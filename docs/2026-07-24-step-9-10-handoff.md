## 10번 commit과 최초 push

### 목표

현재 FieldLog source, config, test와 문서를 실제 의존성과 작업 의미에 따라 나누어 commit하고 `origin/master`에 최초 push한다. push 뒤 원격 branch, commit 순서, 파일 누락과 공개 민감정보 경계를 독립 확인한다.

### 시작 전 실제 상태

| 항목 | 확인 결과 |
| --- | --- |
| local branch | `master`, commit 0개 |
| remote | `origin`이 빈 public repository를 가리킴 |
| index | 초기 Expo template staged 상태와 최종 FieldLog modified·untracked 상태가 혼재 |
| generated output | root `/android`, `/ios`, `.expo/`, module Android `build/`가 ignore됨 |
| Git 작성자 | global identity를 바꾸지 않고 repository-local noreply identity 사용 |

초기 template index를 그대로 commit하면 삭제된 예제 파일까지 포함된 잘못된 중간 snapshot이 생기므로, 기존 index tree를 확인한 뒤 worktree를 바꾸지 않고 index만 비웠다. 이후 각 commit의 대상 파일만 명시적으로 stage했다.
